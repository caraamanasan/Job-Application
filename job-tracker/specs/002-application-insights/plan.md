# Implementation Plan: Application Insights

**Branch**: `002-application-insights` | **Date**: 2026-10-06 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/002-application-insights/spec.md`

## Summary

Add an insights section with an all-time application total and current-status distribution alongside a GitHub-style rolling 12-month daily activity graph. Use the existing unfiltered applications endpoint and derive both summaries in the frontend; do not add a database entity, migration, API endpoint, or runtime dependency.

## Technical Context

**Language/Version**: Python 3.11+; TypeScript 5.7; React 19

**Primary Dependencies**: Flask 3.1, Flask-WTF 1.2, React, lucide-react; no new dependencies planned

**Storage**: Existing local SQLite `applications` table; insights are derived and not persisted

**Testing**: pytest for backend; Vitest and Testing Library for frontend; TypeScript check and Vite production build

**Target Platform**: Local single-user web application, desktop and narrow-screen browsers

**Project Type**: React frontend with Flask web service

**Performance Goals**: Show summaries from the local application collection without a separate network request for each graph; no additional numeric target is needed for the single-user dataset

**Constraints**: Keep data local/private; preserve list search and status filtering; chart values and tooltips must be accessible without color or pointer use; date-only values must not shift across time zones

**Scale/Scope**: One user's existing application history and a fixed rolling 12-month date window; no concurrent-user, import, or export scope
